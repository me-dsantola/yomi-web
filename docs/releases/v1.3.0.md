## Yomi Web 1.3.0

- Avaliações de 1 a 5 estrelas, com um voto editável por conta.
- Em alta com classificação baseada nas notas e na quantidade de avaliações.
- Notas e contagem integradas à estética AMOLED existente, com controles acessíveis de 44 px.
- Recuperação de rascunhos antigos e integração das correções mobile da main.
- Validação automática de testes, TypeScript, build, regras Firestore e navegadores Chromium/WebKit.
- Documentação e fluxo de publicação organizados.

### Implantação

Publicar as regras de `firestore.rules` no projeto Firebase do site para ativar as avaliações. A CI valida essas regras em um projeto demo isolado, sem alterar o banco de produção.

Esta é uma release do site. Não contém um novo APK.
